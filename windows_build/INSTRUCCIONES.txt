================================================
  Meta & Google Ads Manager - Claude Desktop y Code
         Version 2.0  —  Node.js / TypeScript
================================================

REQUISITOS
----------
- Claude Desktop instalado (https://claude.ai/download)
- Tokens de acceso de Meta Ads y/o Google Ads
- NO se requiere instalar Node.js ni ningun otro programa
  (el paquete incluye su propio node.exe)

INSTALACION (3 pasos)
---------------------

1. EJECUTAR EL CONFIGURADOR
   - Doble click sobre "setup.bat"
   - Si Windows muestra aviso de seguridad (SmartScreen), haz click
     en "Mas informacion" y luego "Ejecutar de todas formas"
   - El script detecta Node.js, Claude Desktop y Claude Code, y te da
     a elegir donde instalar:
       [1] Claude Desktop + Claude Code  (ambos)
       [2] Solo Claude Desktop
       [3] Solo Claude Code (CLI/terminal)
   - Si los servidores ya existen, puedes:
       [S] Sobreescribir  — reemplaza MetaAds y GoogleAds existentes
       [A] Agregar faltantes — solo instala los que no estan
       [N] Cancelar

2. COMPLETAR LAS CREDENCIALES
   El script abrira el archivo ".env" en Notepad.
   Rellena los valores segun la plataforma que uses:

   META ADS:
     META_ACCESS_TOKEN=<tu token permanente de Meta Business>

     Como obtenerlo:
     - Ve a developers.facebook.com -> Mis Apps
     - Crea una App Business con permisos de Marketing API
     - Genera un Long-Lived Token en el Explorador de API
     - Activa permisos: ads_read, ads_management, business_management

   GOOGLE ADS (todos los campos son obligatorios si usas Google Ads):
     GOOGLE_ADS_DEVELOPER_TOKEN=<developer token>
     GOOGLE_ADS_CLIENT_ID=<OAuth2 client id>
     GOOGLE_ADS_CLIENT_SECRET=<OAuth2 client secret>
     GOOGLE_ADS_REFRESH_TOKEN=<refresh token>
     GOOGLE_ADS_LOGIN_CUSTOMER_ID=<ID cuenta manager MCC, sin guiones>

     Como obtenerlos:
     - Developer Token: ads.google.com/aw/apicenter
     - Client ID y Secret: console.cloud.google.com/apis/credentials
     - Refresh Token: developers.google.com/oauthplayground
       (scope: https://www.googleapis.com/auth/adwords)
     - Login Customer ID: ID de tu cuenta MCC (si manejas varias cuentas)
       Dejalo vacio si solo tienes una cuenta directa.

   Guarda el archivo .env cuando termines (Ctrl+S en Notepad).

3. REINICIAR CLAUDE DESKTOP / CLAUDE CODE
   - Claude Desktop: Cierra y vuelve a abrir. Los servidores MetaAds
     y GoogleAds apareceran disponibles.
   - Claude Code (terminal): Reinicia la sesion o ejecuta
     claude mcp list para verificar que esten registrados.

COMO USARLO
-----------
Una vez configurado, escribe directamente en Claude lo que necesitas:

  "Lista todas mis cuentas publicitarias de Meta"
  "Mostrame las campanas activas de Google Ads esta semana"
  "Cuanto gastamos en la cuenta X durante mayo?"
  "Hay campanas tirando dinero sin conversiones?"
  "Apaga la campana ID 12345678"
  "Que anuncios tienen errores o rechazos?"

SKILLS INCLUIDOS (solo Claude Code)
-----------------------------------
Si instalaste para Claude Code, se copia tambien el playbook de
"auditoria-meta-ads" en %USERPROFILE%\.claude\skills. Con el, Claude hace
una auditoria completa y ordenada de una cuenta consultando TODAS las
herramientas (rendimiento, campanas, mensajeria, segmentacion) sin saltarse
ninguna. Pruebalo escribiendo, por ejemplo:

  "Dame la auditoria completa de la cuenta del Dr. X"
  "Como va la cuenta de la Dra. Y? Hazme un diagnostico"

DESINSTALAR
-----------
Ejecuta "uninstall.bat" para eliminar MetaAds y GoogleAds de la
configuracion de Claude Desktop y Claude Code. El resto de tus
MCPs no se toca.

SOLUCION DE PROBLEMAS
---------------------
Si algo no funciona:

  1. Verifica que el archivo .env tiene los tokens correctos
     (sin espacios extra, sin comillas alrededor del valor)

  2. Asegurate de que meta_ads.js, google_ads.js y .env estan en la
     misma carpeta que este archivo INSTRUCCIONES.txt

  3. Cierra Claude Desktop completamente (barra de tareas) y
     vuelve a abrirlo

  4. Si ves "Server disconnected", revisa que el .env tiene
     los valores correctos para esa plataforma

  5. Para Claude Code (terminal), ejecuta:
     claude mcp list
     Deberia aparecer MetaAds y/o GoogleAds en la lista.

  6. Verifica que node.exe esta en la misma carpeta que los demas archivos.
     Si falta, descarga de nuevo el paquete completo.
